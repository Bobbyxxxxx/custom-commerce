# E-commerce Store

An online store built with React, featuring product listings, a shopping cart and a responsive layout that works on phone and desktop.


## Features

- Browse products with images, prices and details
- Add to cart, update quantities and remove items
- Responsive design for mobile, tablet and desktop
- FEATURE (e.g. user sign-up/login with Supabase Auth, search, checkout)

## Tech stack

- **Frontend:** NextJs, Typescript, Tailwind
- **Backend:** Supabase (PostgreSQL database, authentication)

## Run locally

```bash
git clone https://github.com/Bobbyxxxxx/REPO-NAME.git
cd REPO-NAME
npm install
npm run dev
```

Create a `.env` file with your Supabase keys:

```
VITE_SUPABASE_URL=your-project-url
VITE_SUPABASE_ANON_KEY=your-anon-key
```
